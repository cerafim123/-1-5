# Заявки жильцов управляющей компании

**Вариант:** 8  
**Дисциплина:** «Языки и средства разработки интернет-приложений»

Проект посвящён учёту заявок жильцов управляющей компании. Практические работы 1–5 относятся к одному проекту и охватывают его разработку от технического задания до REST API.

## Практические работы

- **ПР 1 — техническое задание.** Разработка ТЗ на систему «Заявки жильцов управляющей компании».
- **ПР 2 — клиентская часть.** Клиентское приложение на Vue 3, Vite и Vue Router.
- **ПР 3 — серверная часть и база данных.** Сервер на FastAPI с SQLAlchemy; база данных MySQL.
- **ПР 4 — аналитика и документы.** Экран аналитики с показателями, фильтрами и диаграммами Chart.js. Формирование XLSX-сводки по дому за месяц и PDF-отчёта о просроченных заявках.
- **ПР 5 — REST API.** API с префиксом `/api/v1`, документация OpenAPI, единый формат ошибок, автоматические тесты и файл запросов `.http`.

## Технологии проекта

- Vue 3, Vite, Vue Router;
- Python, FastAPI, SQLAlchemy;
- MySQL;
- Chart.js;
- openpyxl для XLSX;
- ReportLab для PDF;
- pytest для автоматических тестов.

## Запуск

Backend запускается из каталога `backend`:

```bat
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8010 --reload
Настройки подключения к базе данных и секретный ключ задаются в переменных окружения DATABASE_URL и JWT_SECRET_KEY.

Документация API:
http://127.0.0.1:8010/docs
Frontend запускается из каталога проекта, где находится package.json:

npm install
npm run dev
Vite выводит адрес запущенного frontend в терминале.

Тесты и ручные запросы
Автоматические тесты запускаются из каталога backend:
python -m pytest -v
Файл запросов для ручной проверки API: requests.http.

Для защищённых запросов API используется заголовок:

Authorization: Bearer <access_token>
Настройки и секреты
Настройки подключения и секретные ключи не следует хранить в коде или публиковать в репозитории. В репозитории размещается только пример файла настроек без реальных паролей и ключей.
